# canvas-trello-powerup

Instructure Canvas integration with Trello Power-Up

## Features

- Connect to Instructure Canvas account using an access token to allow API access
- Import assignment details from the assignment URL

## Planned Features

- Load and import all assignments for the upcoming week
- Automatically check for assignment completion and mark completed in Trello

## Local Preview

Run `npm run preview`, then open http://127.0.0.1:4173/. The preview uses mock
Canvas and Trello data, so it does not require credentials or create Trello cards.

Run `npm test` to execute the unit tests.
